# Pokémon Arena REVENGE — HD-2D（v2）

`monsterSprite` のアニメ GIF を使った、俯瞰視点のリアルタイム対戦アクションです。
`ダウンロード用/BigKidNation_pokemon_game_videos` の 12 本の動画に出てくる要素をまとめて再現し、
見た目は「荒いドット絵 × ドラクエ1〜3 HD-2D リメイク風のライティング」に作り直しました。

## 起動

`ゲーム起動.command` をダブルクリック（python3 のローカルサーバーで開きます）。
ドット絵化の処理に画素の読み取りが必要なため、`file://` で直接開くと動きません。

## 画づくり

- **顔が読めるドット絵**: GIF の各フレームを読み込み時にドット絵へ変換します（`pixel.js` の `pixelize`）。
  目・口・内側の線など周りより暗い画素を優先して残す縮小、スプライトごと 22 色への減色、1px の暗い外輪郭の 3 段階です。
  世界全体も 1 ドット＝画面 3〜4px の整数倍率で描画し、ドットが崩れません。
- **大きさ＝図鑑の高さ**: `monsterData` の height（m）から体の高さを 28〜86 ドットに対数で割り当てます（`Assets.artHeight`）。
  ピカチュウ 0.4m ≈ 31 ドット、リザードン 1.7m ≈ 54、ギャラドス 6.5m ≈ 75、上限 86（元の GIF より大きくはしません）。当たり判定も見た目の大きさに追従します。
- **スムーズな動き**: GIF 本来のアニメに加え、歩行に合わせた上下バウンド、着地の伸び縮み、技の溜めの沈み込み、ヒット時のつぶれ、ダッシュの残像があります。
- **HD-2D ライティング（WebGL）**: 環境光と照明の乗算、ブルーム（発光のにじみ）、上下をぼかすティルトシフト、霧、木漏れ日の光線、カラーグレーディング。
  エフェクトはディザ（網点）とポスタリゼーション（減色）を通すので、レトロなのに光ります。
- **UI**: ドラクエ風の紺地に白い二重枠のウィンドウと、ドットフォント（DotGothic16 / Press Start 2P）。
- **バトル以外は元の絵のまま**: 荒いドット化はバトルフィールドの中だけ。タイトルを歩くモンスター、選択画面のずかんパネル、
  バトル中の HP パネルの顔・控えのアイコン・VS カードは、monsterSprite の元の GIF をそのまま（整数倍で）くっきり表示します（`Assets.hd`）。
  実況はタイプライター表示で「こうかは ばつぐんだ！」などを流します。

## 8方向の向きと初動モーション

- **8 方向（第1世代）**: 第1世代 220 フォームのうち 204 フォームは、本物の 8 方向の絵で表示します（`monsterSprite/gen1/…/<id>.png`。南・南東・東・北東・北・北西・西・南西）。
  北は真後ろ、南は真正面、東は右向きの横顔、西は左向きの横顔、斜めはそれぞれの 3/4 の向き。
  元の絵は `../tools/8dir_builder/raw_5dir_cache` の多方向キー画像（読むだけ）。どの絵がどの向きかをエージェント 8 人で 1 枚ずつ目で分類し
  （`tools/dir8_labels/labels.json`）、白背景と足元の影を消し、無い向きは反対側の絵を左右反転して埋めています。仕上がりも 2 回、目で確認しました。
  作り直し: `PLAYWRIGHT=<playwright のパス> node tools/build_dir8.js tools/dir8_labels/labels.json tools/dir8_labels/list.json`
  （除外と個別設定は `tools/dir8_labels/overrides.json`）。
  元画像に後ろ・横の絵が無い／崩れている 16 フォーム（ベトベトン・フリーザー・カイリュー・マタドガス 2 種・ドードリオ・
  メガプテラ・キョダイリザードン・メガフーディン・アローラダグトリオ・キョダイラプラス・アローラニャース・ガラルポニータ・ヤドラン・ナッシー・ガラルサンダー）と色違いは、
  monsterSprite の前後 4 枚から作る 8 方向（`game/js/dir8.js`）で表示します。
- 向きを変えるときは、間の向きを 1 段ずつ（約 0.04 秒ごと）経由して回ります。止まっているときは 1px だけ呼吸します。
- **初動モーション**（`game/js/motion.js`。不思議のダンジョンのアニメ表のタイミングを参考にしたキーフレーム）
  - たいあたり系の近接: しゃがんで下がる → ヒットの瞬間に体ひとつ分つっこむ → 戻る
  - きりさく系: 体を起こして後ろへ反る → 振り下ろしながら踏み込む
  - 突進・とびかかり: しゃがんで震える → 飛び出す
  - 物理の投げ技: 振りかぶる → 投げる。特殊の弾・状態異常: 少し引いて → 押し出す
  - 息・炎・水のビーム: のけぞって → 吐き出す姿勢のままビームの間止まる
  - 特殊ビーム・光柱・落雷: 震えながら浮き上がってためる → 放つ瞬間に前へ
  - サイコブレイク・ワイドフォース: 大きく浮き上がり、強く震える。サイコキネシス: 腕を伸ばしたまま → たたきつけで振り下ろす
  - じしん等の物理の範囲技: しゃがむ → 跳ぶ → 着地の瞬間が発動
  - 能力アップ・回復・まもる: しゃがんでから 8 方向をくるりと一回転して伸び上がる
  - 被弾: 飛ばされる向きにのけぞる

## ステータスで出る個性（`monsterData` から）

- **すばやさ**: 移動速度と回避のクールダウン。**おもさ**: ふっとびにくさ。重さ約 200kg からはドスドス歩いて地面が揺れ、約 250kg からは弱い技でひるみません。
- **体型（shape）で歩き方が変わる**: ボール型・ブロブ型はぽよんと跳ね、ヘビ・魚・触手型はくねくね、四足は軽やかに駆け、ひこう・ふゆうは浮遊します。
- **とくせい（約 70 種が実際に効く）**: いかく・ふゆう・がんじょう・もうか/げきりゅう/しんりょく/むしのしらせ・ちくでん/ちょすい/もらいび・
  せいでんき/ほのおのからだ/どくのトゲ・すいすい/ようりょくそ・ひでり/あめふらし/すなおこし/ゆきふらし・かそく・じしんかじょう・テクニシャン・
  てきおうりょく・マルチスケイル・いたずらごころ ほか（`game/js/ability.js`）。発動すると第 5 世代風の「とくせいバー」が出ます。
- **伝説・幻**は登場時に光の柱と地響き。セレクト画面でモンスターにカーソルを合わせると、ずかんパネル（分類・高さ・重さ・とくせい・種族値・動きの特徴）が出ます。

## 技エフェクト（レトロ強化）

- ヒットのたびに星形のヒットスパーク＋集中線＋多重の衝撃リング＋落ちる四角い火花。強打は放射ブラーとタイプ色の画面フラッシュ。
- 急所・効果ばつぐんの大ダメージと K.O. では、昔の RPG のような一瞬のネガ反転フラッシュ（単発・連続点滅はしません）。
- 溜めのある技は足元から円形に光の粒が放射状に広がる。威力 90 以上は放つ瞬間に画面がタイプ色に光ります。
- 弾には残像と十字のきらめき、ビームには流れるエネルギーリングと両端のきらめき。落雷・岩・光柱・のしかかりの着地は爆発の光柱つき。

## ミュウツー（6対6 動画の再現）

`sample10_6対6バトル.mp4` のミュウツーに合わせ、技はサイコブレイク・シャドーボール・サイコキネシス・ワイドフォース。
テレポートは回避（Space）に組み込みました（ミュウツー・ミュウ・ケーシィ系は転がる代わりに短くテレポート）。

- **登場**: 会場が紫の闇に沈み、紫の波動が広がります。
- **ワイドフォース（フィールドが持ち上がる技）**: 狙った場所の地面に紫のひびが走り（約 0.5 秒、出ればかわせる）、
  フィールドそのもの（線や焦げあともそのまま）が 6 枚の岩盤に割れて持ち上がり、下に暗い穴がのぞきます。上にいた相手は岩盤ごと浮かされ、
  最後に岩盤ごとたたきつけられて大ダメージ。周りにも衝撃波。落ちた岩盤は少しずれて、ひび割れとして残ります。
- **サイコブレイク**: 赤い照準レーザーで約 0.5 秒ねらい（その間に横へよければかわせます）、フィールドの端まで届く太いマゼンタのビームを撃ちます。
  地面には紫の溝がずっと残り、ビームの先にはクレーター。
- **シャドーボール**: 黒い核に青い縁の闇の玉。ゆるく追尾し、着弾すると闇の爆発とクレーター。
- **サイコキネシス**: 光の糸を伸ばして相手をつかみ、足元の地面ごと持ち上げてからたたきつけます（糸は横に動くとかわせます）。
- **テレポート**: 光の柱と、引き伸ばされて消える残像。
- ふだんから足元に紫のオーラ。CPU はサイコブレイクの照準線やつかみの糸を見て回避します。

## トレーナー

試合ごとに、ハートゴールド・ソウルシルバーとファイアレッド・リーフグリーンのフィールドキャラ（人物のみ 241 人）から
ランダムに 2 人が選ばれ、フィールドの左右に立ちます。ボールを投げるときは一歩踏み出し、会場が盛り上がると跳ねます。

## モード

| モード | 内容 |
| --- | --- |
| バトル | 最大 6 対 6 のリアルタイム戦。プレイまたは観戦。 |
| トーナメント | 8 体の勝ち抜き戦。ROUND ONE → TWO → FINAL、勝者バナーと優勝演出。1 体だけ自分で操作も可能。 |
| ミニバトル | サイトのミニゲーム風のターン制 3 対 3。コマンド選択で、技は実際のエフェクトで演出されます。 |
| トレーニング | 攻撃してこない相手で練習（ROUND 1・TRAINING）。 |

## アリーナ（11 種）

リーグスタジアム（芝）、つちのグラウンド、いしだたみコート、サンド・コロシアム、ボールドーム、
こおりのリンク（滑る）、マグマのふんか口（溶岩でダメージ）、ウォーターフィールド（浮き台・水中は減速、みずタイプは加速）、
クリスタル・ケイブ（星空の泉）、うちゅうステージ（吹き飛びやすい）、よるのそうげん（ホタルと霧）。
観客は歓声に合わせて立ち上がり、電光掲示板に対戦カードが流れます。試合開始時は照明が 1 灯ずつ点きます。

## 動画から再現した主な演出

- VS カード、3・2・1・GO、K.O.!（BOOM!）、ROUND ○○ WINNER バナー
- 技名の吹き出し、コンボ数（○ HITS）、SUPER EFFECTIVE / CRITICAL! の表示
- かえんほうしゃ＝火の玉の連なり、ハイドロポンプ＝渦巻く水流、かみなり＝落雷
- ストーンエッジ / シャドークロー＝地面から突き出る岩・結晶の列
- のしかかり＝ジャンプからの着地衝撃、ソーラービーム＝空からの光の柱
- えんまく、テレポート、かげぶんしん（分身）、まもる、天候（すなあらし・あめ・ひざし・あられ）とその残り時間
- メガシンカ / キョダイマックス、色違い、トレーナーのボール投げ

## テスト用 URL

```
game/index.html?auto=charizard,blastoise;mewtwo,gengar&arena=water&mode=watch|play|turn&ff=12&freeze=1&seed=42
```

`weather=sand|rain|sun|hail`、`round=ROUND%20ONE`（勝者バナー）、`dbg=1`（FPS 表示）も使えます。
前バージョン（v1）は `../_backup_arena_v1/` に残してあります。
